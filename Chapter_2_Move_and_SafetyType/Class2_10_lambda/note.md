# 第十一课：让代码像水一样流动 —— Lambda 表达式与就地数据转换
在前面的课程中，Lambda 已经作为“配角”出现过几次（比如 `std::visit` 里的匿名函数）。但在现代 C++ 中，Lambda 绝对是主角。
在旧时代的 C++ 中，如果你想对一个数组做过滤、转换，你必须去别的地方写一个独立的函数，或者写一个丑陋的仿函数类。这打断了你阅读代码的“心流”。
Lambda 的本质是：**随手写的、用完即弃的闭包函数**。它让你能在**确切需要逻辑的地方，就地写下逻辑**。
更可怕的是，当 Lambda 结合上第七课学过的**移动语义**时，它能衍生出 C++14 最迷人的特性：**初始化捕获（Init Capture）**。你可以把一个外部对象直接“偷”进 Lambda 的体内，变成它私有的状态。
## 1. 核心武器库
*   **过滤剔除**：`std::erase_if(container, [](元素类型 e) { return 条件; })` （C++20 引入，极其优雅，直接干掉符合条件的元素）。
*   **就地转换**：`std::transform(开始, 结束, 开始, [](元素类型 e) { return 新值; })` （用新值覆盖旧值）。
*   **移动捕获**：`[name = std::move(外部变量)]`。这表示把外部的变量“连根拔起”搬进 Lambda 里，外部变量随后变为空壳。

## 课后实操题
请创建一个全新的代码文件，**只贴代码，不要废话**。
⚠️ **注意**：本课使用了 C++20 特性，编译时必须加上 `-std=c++20`（即 `g++ main.cpp -std=c++20 -g && ./a.out`）。
**任务要求：**
1. 引入 `<iostream>`, `<vector>`, `<algorithm>`, `<string>`, `<cmath>`。
2. 在 `main` 中初始化一个雷达点距离的 `std::vector<double> distances = {1.5, 0.2, 8.9, 0.1, 5.5, 15.2};`。
3. **第一步：就地过滤**。
   使用 `std::erase_if`，配合一个 Lambda，把小于 `0.5` 的无效噪点直接从 `distances` 中删掉。
4. **第二步：就地转换**。
   使用 `std::transform`（自己查一下它需要几个迭代器参数），配合一个 Lambda，把剩下的距离值全部**平方**（使用 `std::pow(d, 2)`），覆盖原数据。
5. **第三步：带状态地遍历（移动捕获）**。
   在 `main` 里定义一个字符串 `std::string tag = "Radar_Squared";`。
   使用 `std::for_each` 遍历转换后的 `distances`，Lambda 的捕获列表**必须写成 `[tag = std::move(tag)]`**。
   在 Lambda 内部打印：`std::cout << "[" << tag << "] " << d << " ";`。
6. 在 `for_each` 结束后，尝试再打印一次 `tag`（看看它还是原来的字符串吗？体会移动捕获的威力）。
请提供你的代码解答。
