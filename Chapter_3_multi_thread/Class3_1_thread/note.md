# 一、核心概念点拨

1. `std::thread`：C++11 原生线程封装类，创建线程对象时线程立即启动，线程对象只可移动、不可拷贝，必须通过 std::move 转移所有权。

2. `join()`：阻塞当前线程，等待子线程执行完毕再继续；IMU 实时数据处理中必须用它保证数据处理完成，避免主线程提前退出丢失数据。

3. `detach()`：将子线程分离为后台线程，脱离主线程管控；IMU 高频数据流场景严禁滥用，极易导致数据未处理完程序退出、内存泄漏。

4. 线程传参核心：传参默认拷贝，传递大型 IMU 数据块时，结合 std::unique\_ptr + std::move 实现零拷贝转移数据所有权，契合你已掌握的移动语义。
